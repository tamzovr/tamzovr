# Dual Cam REC Sync — Support

Dual Cam REC Sync is an iPhone app that sends parallelized REC START and REC STOP commands over wired USB to two cameras. Tested with **two Sony ZV-E1 cameras**. Compatibility with other camera models is not confirmed.

## Before use

Connect both cameras to the iPhone through a suitable USB connection. Check the app's two connection indicators. A brief record-and-stop immediately before the main take is recommended. Confirm the actual REC state on both camera bodies after each command.

Parallel command dispatch does **not** guarantee identical command issuance or recording start/stop times, and frame-level synchronization is not guaranteed. Recording state is not read automatically.

## Help

If the app does not recognize both cameras, verify power and USB connections and check each camera's remote USB settings. If a command fails, check both camera REC indicators before retrying.

Contact: **vr3d.support@gmail.com**

# Dual Cam REC Sync — サポート

本アプリはiPhoneからUSB有線接続した2台のカメラへ、並列化されたREC START／REC STOPコマンドを送信します。**Sony ZV-E1を2台使用した動作を確認済み**です。それ以外の機種については動作確認が必要です。

## 使用前に

2台を適切なUSB接続環境でiPhoneに接続し、アプリの接続表示を確認してください。本録画直前に短時間の録画・停止を行うことを推奨します。各操作後はカメラ本体のREC表示を確認してください。

2台のカメラに向けて並列化された送信処理を行います。

2台への厳密なコマンド発行タイミングには誤差が存在します。

フレーム単位の同期精度は保証しません。録画状態は自動取得しません。

## お問い合わせ

接続できない場合は、電源、USB接続、カメラ側のUSBリモート制御設定を確認してください。送信エラーが表示されたときは、両カメラのREC表示を確認してから操作してください。

連絡先：**vr3d.support@gmail.com**
