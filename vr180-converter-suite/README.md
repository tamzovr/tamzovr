# VR180 Converter Suite Support

VR180 Converter Suite is a macOS app for creating VR180 video from a pair of fisheye videos.

## Main features

- Dual fisheye to SBS VR180 conversion
- Dual fisheye to HEQ180 conversion
- Dual HEQ to SBS conversion
- Left/right synchronization and trimming
- Fisheye circle diameter and center review
- Automatic center estimation
- Vertical alignment
- VR180 metadata injection
- Batch conversion
- Camera + lens presets
- HEVC Main 10 output
- Source-audio output support
- Automatic numbered filenames to protect existing outputs

The default SBS output size is 8192 × 4096. Custom output sizes are also available.

## Free version and In-App Purchase

The free version allows video exports up to 15 seconds.

The one-time non-consumable In-App Purchase **Unlock Export Duration** removes the video export duration limit. Purchases are handled through Apple StoreKit.

## Basic workflow

1. Select the source fisheye videos.
2. Review or adjust fisheye circle parameters when necessary.
3. Set synchronization and trimming.
4. Review vertical alignment when necessary.
5. Convert to HEQ/SBS VR180 and apply VR180 metadata.
6. Save the finished video.

Depending on the source material and shooting conditions, fisheye diameter/center, synchronization, or vertical alignment may require manual review or adjustment.

# VR180 Converter Suite サポート

VR180 Converter Suite は、左右2本の魚眼動画からVR180動画を作成するためのmacOSアプリです。

## 主な機能

- 魚眼×2 → SBS VR180変換
- 魚眼×2 → HEQ180変換
- HEQ×2 → SBS変換
- 左右動画の同期・切り出し
- 魚眼円の直径／中心確認
- 自動Center推定
- 縦位置合わせ
- VR180メタデータ付与
- 複数ジョブの一括変換
- カメラ＋レンズプリセット
- HEVC Main 10出力
- 元動画の音声を利用した出力
- 既存出力を保護する自動連番保存

標準のSBS出力サイズは8192 × 4096です。必要に応じてカスタム出力サイズも設定できます。

## 無料版とアプリ内課金

無料版では、動画の書き出し時間は最大15秒です。

買い切りの非消耗型アプリ内課金 **「書き出し時間制限の解除」** を購入すると、動画の書き出し時間制限を解除できます。購入処理にはApple StoreKitを使用します。

## 基本的な流れ

1. 左右の魚眼動画を選択します。
2. 必要に応じて魚眼円の直径・中心を確認または調整します。
3. 左右動画の同期と切り出し範囲を設定します。
4. 必要に応じて縦位置合わせを確認します。
5. HEQ／SBS VR180変換とVR180メタデータ付与を実行します。
6. 完成動画を保存します。

入力素材や撮影条件によっては、魚眼円の直径・中心、同期、縦位置の確認・調整が必要になる場合があります。
